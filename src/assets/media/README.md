# Marka görselleri

Bu klasöre konan dosyalar ad kuralıyla otomatik bağlanır (bkz. `src/data/media.ts`). Dosya yokken ilgili alan etiketli yer tutucu olarak görünür.

| Dosya | Alan | Önerilen ölçü |
|---|---|---|
| `acilis-masaustu.jpg` | Ana sayfa açılış fotoğrafı, masaüstü | 1440×560 (≈ 2.6:1) |
| `acilis-mobil.jpg` | Ana sayfa açılış fotoğrafı, mobil | 780×840 (≈ 0.93:1) |
| `koleksiyon.jpg` | Koleksiyon tanıtım görseli | 16:9 |
| `giris.jpg` | Giriş / kayıt görsel alanı | 3:4 |
| `logo.svg` (veya `.png`) | Header logosu | yükseklik 32 px'e ölçeklenir |
| `uretim-video.mp4` + `uretim-video-kapak.jpg` | Üretim videosu ve kapak | 16:9 |
| `uretim-kesim.jpg`, `uretim-dikim.jpg`, `uretim-kalite.jpg` | Üretim aşamaları | 4:5 |
| `urun-01-on.jpg`, `urun-01-arka.jpg`, `urun-01-model.jpg`, `urun-01-kumas.jpg` | Ürün 01 görünüşleri (01–24) | 3:4 |

Yalnızca markanın sağladığı fotoğraflar kullanılır; stok, yapay zekâ veya referans marka görseli konmaz.
